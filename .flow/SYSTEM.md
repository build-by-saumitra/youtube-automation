# System Manual: YouTube Automation Lifecycle

## Development Framework: RPI (Research ➔ Plan ➔ Implement)
1. **Research Phase:** Scoping, options evaluation, and architecture trade-offs (`RESEARCH.md`). Requires explicit user approval gate.
2. **Plan Phase:** Technical spec, file manifest, task breakdown, and API contracts (`SPEC.md`). Requires explicit user approval gate.
3. **Implement Phase:** Execution of tasks, unit/integration testing, summary log (`SUMMARY.md`), and memory update (`MEMORY.md`).
